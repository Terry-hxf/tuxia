图片工具指南

如何选择合适的图片工作台

处理前先确认目标

如果目标是减小文件体积，优先使用图片压缩；如果需要固定宽高或比例，使用尺寸调整或裁剪；如果要把图片放进网页、邮件或文档，可以先用格式转换选择更合适的 PNG、JPG 或 WebP。

隐私和第三方上传

大多数工具只使用浏览器能力处理图片。图片在线链接工具会使用你填写的 ImgBB API Key 直接上传到 ImgBB，适合需要公开链接的场景；如果图片包含敏感信息，建议先用局部擦除/马赛克处理。

如何选择图片格式

JPEG 适合照片和复杂图片，文件小且兼容性最广。PNG 适合需要透明背景或包含文字的图片。WebP 在现代网页中最省空间，通常比 JPEG 小 25-35%。SVG 适合 logo 和图标，可任意放大而不失真。如果不确定，可用格式转换工具先预览再导出。

隐私优先：本地处理的意义

与需要上传图片的云端编辑器不同，TUXIA 的 12 款工具中有 11 款完全在你的浏览器中执行。你的照片、文件和截图永远不会离开你的设备——没有上传等待时间、没有服务器储存、完全保护隐私。只有图片在线链接工具会使用你自己的 API Key 直接将图片发送到 ImgBB。
