關於 TUXIA 圖匣

最後更新: 2026年7月23日

我們的故事

TUXIA 圖匣誕生於一個簡單的觀察：大多數人每天都需要處理圖片——調整商品照片尺寸、壓縮截圖用於郵件、裁切頭像、或為連結產生 QR Code——但可用的工具要麼需要安裝桌面軟體，要麼需要註冊帳號，要麼需要把檔案上傳到未知的伺服器。

我們問自己：如果最常見的圖片處理任務都能直接在瀏覽器中完成，不需要任何麻煩，會是什麼樣子？

這個問題催生了 TUXIA 圖匣——一個包含 12 個專注工作區的線上工具箱，你可以直接在瀏覽器中上傳、預覽、編輯和匯出圖片。無需下載。無需帳號。大多數工具不需要上傳到伺服器。打開頁面就能開始使用。

TUXIA 圖匣的與眾不同

本機優先處理

TUXIA 的大多數工具——包括圖片壓縮、格式轉換、尺寸調整、裁切、浮水印、局部擦除/馬賽克、取色、Base64 互轉、QR Code 產生與解碼、EXIF 中繼資料查看——都使用 Canvas API 和 FileReader API 在你的瀏覽器中本機執行。你的圖片不會被上傳到 TUXIA 伺服器。這意味著更快的處理速度、更強的隱私保護和零雲端依賴。

12 個專注工作區

TUXIA 沒有把所有功能塞進一個雜亂的編輯器，而是為每個圖片任務設計了獨立的工作區。壓縮工具有原圖和壓縮後的比較面板。QR Code 產生器有即時預覽以及顏色和樣式控制。取色器會展示配色板，你可以懸停在圖片上讀取單個像素的顏色。每個工具都圍繞其特定工作流程設計。

無需註冊和登入

TUXIA 是一個靜態網站。沒有使用者資料庫、沒有會員體系、無需登入。你造訪頁面、使用工具、下載結果。我們不會收集、儲存或追蹤你的圖片或個人資料。唯一的例外是圖片線上連結工具——它會使用你自己的 ImgBB API Key 將圖片從瀏覽器直接發送到 ImgBB——即使如此，TUXIA 也不會看到或儲存你的檔案。

多語言支援

TUXIA 提供英文、簡體中文和繁體中文三種語言版本。每個工具頁面、指南、隱私政策和使用條款都經過完整的翻譯，以服務不同地區的使用者。

基於現代 Web 標準構建

TUXIA 使用 Hugo（快速靜態網站產生器）構建，並透過 GitHub Pages 部署。工具使用原生 JavaScript 配合 Canvas API、FileReader API 和現代瀏覽器能力。我們整合了一些第三方函式庫——exif.js 用於中繼資料讀取、jsQR.js 用於 QR Code 解碼、qr-code-styling.js 用於 QR Code 產生——所有函式庫都本機載入，不依賴外部 CDN。

我們的承諾

隱私優先的設計。 因為大多數工具在本機處理圖片，你的檔案始終留在你的裝置上。我們特意設計了不需要接收、代理或儲存使用者圖片的架構。

永遠免費。 TUXIA 完全免費使用，沒有隱藏費用、沒有付費會員、沒有鎖定功能。我們透過廣告來維持網站營運，而不是向使用者收費。

持續改進。 我們會主動關注瀏覽器相容性、效能和可用性。工具會定期更新以支援新的格式、修復邊緣情況和改善編輯體驗。

誠實透明。 我們的隱私政策和使用條款用通俗易懂的語言撰寫，讓你清楚了解網站如何運作以及資料如何處理。如有問題或回饋，請造訪我們的聯絡頁面。
