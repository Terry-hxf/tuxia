QR Code 產生工具指南與常見問題

輸入文字或連結即可產生 QR Code，支援尺寸、容錯等級、顏色、樣式、Logo 和 PNG/SVG 匯出，適合分享、印刷和營運素材。

QR Code 已成為連接實體世界和數位內容的重要橋樑，出現在產品包裝、餐廳菜單、活動票券、名片和行銷素材等各種場合。TUXIA 的 QR Code 產生器讓你能完全掌控 QR Code 的外觀，同時確保其可掃描性。你可以調整尺寸（以像素為單位）、選擇四種容錯等級（L、M、Q、H）、自訂前景色和背景色、切換方形點和圓角樣式、修改角落圖案，還可選擇性地在中央嵌入標誌圖示。即時預覽會在你做出變更時立即更新，方便你在匯出 PNG 或 SVG 前嘗試不同的設計。所有產生過程都在瀏覽器本機中執行，使用 qr-code-styling 程式庫。

使用場景

品牌行銷素材

建立符合品牌色彩並在中央嵌入標誌的 QR Code。匯出 SVG 用於印刷品如傳單、海報和產品包裝，利用可縮放向量圖形確保印刷品質。

實體到數位連結

從任何網址產生 QR Code，放在名片、活動標示或產品標籤上。使用者用手機相機掃描後即可立即造訪你的網站、社群媒體或登陸頁面。

Wi-Fi 與聯絡人分享

將 Wi-Fi 網路憑證或聯絡資訊（vCard 格式）編碼到 QR Code 中。訪客掃描後即可自動連線 Wi-Fi，新聯絡人掃描後可將你加入通訊錄，省去手動輸入的麻煩。

與其他方案比較

許多線上 QR Code 產生器會加上浮水印、要求註冊或限制產生數量。TUXIA 的產生器沒有限制、沒有浮水印，也不需要註冊，所有樣式設定和匯出都在本機執行。不過，TUXIA 不追蹤掃描分析資料，如果你需要掃描次數統計，可能需要使用專門的 QR Code 管理平台。

技術說明

  • 較高的容錯等級（Q、H）能讓 QR Code 在被部分遮蓋或損壞時仍可讀取，但會增加模組數量，使圖案更密集。
  • 嵌入標誌時請使用 Q 或 H 容錯等級。標誌會遮蓋部分 QR Code 模組，較高的容錯等級可以補償被遮蓋的區域。
  • QR Code 顏色必須保持足夠的對比度。深色前景搭配淺色背景效果最佳，避免淺色配白色背景或深色配黑色背景。
  • SVG 匯出會產生可縮放至任何尺寸而不失真的向量輸出，非常適合印刷；PNG 匯出則適合快速數位分享。
  • 印刷用的 QR Code 建議最小尺寸為 2 × 2 公分，數位顯示則以 200 × 200 像素為實用下限。

最佳實踐

  • 在印刷或發布前，務必使用至少兩支不同的手機（iOS 和 Android）實際掃描測試 QR Code。
  • 標誌、印刷品和任何需要縮放的情況使用 SVG 匯出，快速數位分享使用 PNG。
  • 標誌尺寸保持在 QR Code 面積的 20% 以下，使用透明背景的 PNG 標誌，並保留足夠的內邊距。
  • 在淺色和深色模式下都測試顏色組合，確保對比度在不同顯示條件下都能正常運作。

適合使用

  • 把網址、文字或短訊息產生 QR Code。
  • 自訂 QR Code 尺寸、容錯等級、前景色、背景色、點樣式和 Logo。
  • 匯出 PNG 或 SVG，用於網頁、印刷和營運素材。

使用方式

  1. 輸入需要編碼的文字或連結。
  2. 調整尺寸、容錯等級、顏色、樣式和可選 Logo。
  3. 預覽 QR Code 並選擇 PNG 或 SVG 下載。
隱私說明： QR Code 產生在瀏覽器本機完成，你輸入的文字不會送到 TUXIA 伺服器。

常見問題

QR Code 可以匯出 SVG 嗎？

可以。SVG 適合需要放大或印刷的場景。

可以加入 Logo 嗎？

可以。建議搭配較高容錯等級，並在匯出後實際掃碼測試。
