## 我们的故事

TUXIA 图匣诞生于一个简单的观察：大多数人每天都需要处理图片——调整商品照片尺寸、压缩截图用于邮件、裁剪头像、或为链接生成二维码——但可用的工具要么需要安装桌面软件，要么需要注册账号，要么需要把文件上传到未知的服务器。

我们问自己：**如果最常见的图片处理任务都能直接在浏览器中完成，不需要任何麻烦，会是什么样子？**

这个问题催生了 TUXIA 图匣——一个包含 12 个专注工作台的在线工具箱，你可以直接在浏览器中上传、预览、编辑和导出图片。无需下载。无需账号。大多数工具不需要上传到服务器。打开页面就能开始使用。

## TUXIA 图匣的与众不同

### 本地优先处理

TUXIA 的大多数工具——包括图片压缩、格式转换、尺寸调整、裁剪、水印、局部擦除/马赛克、取色、Base64 互转、二维码生成与解码、EXIF 元数据查看——都使用 Canvas API 和 FileReader API 在你的浏览器中本地运行。你的图片不会被上传到 TUXIA 服务器。这意味着更快的处理速度、更强的隐私保护和零云端依赖。

### 12 个专注工作台

TUXIA 没有把所有功能塞进一个杂乱的编辑器，而是为每个图片任务设计了独立的工作台。压缩工具有原图和压缩后的对比面板。二维码生成器有实时预览以及颜色和样式控制。取色器会展示配色板，你可以悬停在图片上读取单个像素的颜色。每个工具都围绕其特定工作流设计。

### 无需注册和登录

TUXIA 是一个静态网站。没有用户数据库、没有会员体系、无需登录。你访问页面、使用工具、下载结果。我们不会收集、存储或追踪你的图片或个人数据。唯一的例外是图片在线链接工具——它会使用你自己的 ImgBB API Key 将图片从浏览器直接发送到 ImgBB——即使如此，TUXIA 也不会看到或保存你的文件。

### 多语言支持

TUXIA 提供英文、简体中文和繁体中文三种语言版本。每个工具页面、指南、隐私政策和使用条款都经过完整的翻译，以服务不同地区的用户。

### 基于现代 Web 标准构建

TUXIA 使用 Hugo（快速静态站点生成器）构建，并通过 GitHub Pages 部署。工具使用原生 JavaScript 配合 Canvas API、FileReader API 和现代浏览器能力。我们集成了一些第三方库——`exif.js` 用于元数据读取、`jsQR.js` 用于二维码解码、`qr-code-styling.js` 用于二维码生成——所有库都本地加载，不依赖外部 CDN。

## 我们的承诺

**隐私优先的设计。** 因为大多数工具在本地处理图片，你的文件始终留在你的设备上。我们特意设计了不需要接收、代理或存储用户图片的架构。

**永远免费。** TUXIA 完全免费使用，没有隐藏费用、没有付费会员、没有锁定功能。我们通过广告来维持网站运营，而不是向用户收费。

**持续改进。** 我们会主动关注浏览器兼容性、性能和可用性。工具会定期更新以支持新的格式、修复边缘情况和改善编辑体验。

**诚实透明。** 我们的[隐私政策](/zh/privacy/)和[使用条款](/zh/terms/)用通俗易懂的语言撰写，让你清楚了解网站如何运作以及数据如何处理。如有问题或反馈，请访问我们的[联系页面](/zh/contact/)。
